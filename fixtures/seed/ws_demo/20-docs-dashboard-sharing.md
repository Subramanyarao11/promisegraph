# Sharing and embedding dashboards

Synthetic product documentation (fictional), product version 4.2.

- **Invite**: share with workspace members or invite guests by email; guests need an account.
- **Share link**: creates a link with an expiry date. If the organisation enables
  **Require authentication for shared links**, links require login; otherwise anyone with the link can view.
- **Embedding**: iframe embedding of authenticated dashboards is supported. Signed, token-based embedding for
  customer portals with per-viewer filters is not yet available.
