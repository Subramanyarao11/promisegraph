# Audit log

Synthetic product documentation (fictional), product version 4.2.

The audit log records admin and security events: sign-ins, role changes, SCIM changes, share-link creation,
export schedule changes and API token use. Admins can filter the last 90 days in the UI and download up to
365 days as CSV under **Admin > Audit log > Download**. Streaming audit events to an external SIEM is not supported.
